# Summit Comfort HVAC

## Client handoff

This folder contains the branded Business Hub for Summit Comfort HVAC. It is a private, local-first workflow manager built for hvac operations.

## Access
- App URL: https://superwrldcoin.github.io/ai-automation-service/clients/summit-comfort-hvac/
- Support: hello@vividstatic.com
- Local app folder: summit-comfort-hvac/

## Included
- Customer list and contact records
- Quote + invoice workflow
- Follow-ups for due and overdue jobs
- Editable pricebook and settings
- Offline-capable app experience

## Notes
- Data stays local to the device and browser unless a separate backend is added later.
- For support, contact hello@vividstatic.com.
